# منصة السادة الركابية الرقمية الموحدة في السودان 🇸🇩

مرحباً بك في المستودع البرمجي الرسمي لمنصة **السادة الركابية**، وهي البوابة الرقمية المتكاملة والديوان الرسمي الجامع لأبناء السادة الركابية في جمهورية السودان وخارجها. تهدف هذه المنصة إلى توثيق الأنساب، وتقديم الخدمات التكافلية والاجتماعية، وتسهيل التواصل وبث الأخبار والبيانات الرسمية تحت مظلة الأمانة العامة.

---

## 🗄️ دليل تهيئة وتطبيق قاعدة بيانات Supabase يدوياً (Database Setup)

المنصة تعتمد كلياً على Supabase كمصدر أساسي ومباشر للبيانات. لتهيئة مشروع جديد على Supabase وتجهيز الهيكل التنظيمي الكامل يدوياً، يرجى اتباع الخطوات التالية عبر **Supabase Dashboard**:

### الخطوة 1: تطبيق ملف الهيكل التنظيمي (Schema Migration)
1. افتح مشروعك في منصة [Supabase Dashboard](https://supabase.com/dashboard).
2. من القائمة الجانبية، انتقل إلى قسم **SQL Editor**.
3. اضغط على **New query**.
4. افتح الملف المرفق في المستودع: `supabase/migrations/001_initial_institutional_schema.sql`.
5. انسخ كامل محتوى الملف، والصقه داخل محرر SQL في Supabase.
6. اضغط على زر **Run** لتشغيل الاستعلام.
   * سيقوم الاستعلام بإنشاء جميع الإضافات (Extensions)، الأنواع المخصصة (Enums)، الترقيم التسلسلي، الجداول الـ 30+ المرتبطة بعلاقات المفاتيح الأجنبية، الدوامات (Triggers)، وسياسات الأمان على مستوى الصفوف (RLS) بأعلى معايير الحوكمة.

### الخطوة 2: تطبيق البيانات التأسيسية والنظامية (Seed Data)
1. في **SQL Editor**، أنشئ استعلاماً جديداً (**New query**).
2. افتح الملف المرفق: `supabase/seed.sql`.
3. انسخ كامل المحتوى، والصقه في المحرر.
4. اضغط على زر **Run**.
   * سيتم إدراج خطط العضوية المعتمدة، طرق الدفع المتاحة (بنكك، أوكاش، فوري)، الدوائر التخصصية للأمانة العامة، والأدوار الإدارية النظامية.
   * **ملاحظة:** الملف خالٍ تماماً من أي حسابات أو أرقام وهمية أو مبالغ تبرعات صورية.

## 🌟 مميزات المنصة الرئيسية

1. **الخط العربي الاحترافي (Tajawal):** تم تزويد الموقع بخط "تاجوال" الراقي والأنيق لضمان تجربة قراءة فائقة الجودة تدعم الاتجاه من اليمين إلى اليسار (RTL) بشكل مثالي ومتكامل مع الهوية البصرية الفخمة (الأخضر الزمردي الملكي والأمبر الذهبي العتيق).
2. **لوحة التحكم الإدارية الشاملة (`/admin`):** لوحة تحكم عصرية ومحمية تمكن المشرفين من إدارة محتوى الموقع بالكامل دون الحاجة لتعديل الكود المصدري:
   - **مراجعة إيصالات الدفع:** معاينة صور الإشعارات المرفوعة بروابط آمنة ومؤقتة (Signed URLs)، واعتماد أو رفض المعاملة مع كتابة سبب الرفض.
   - **الشفافية المالية:** سجل معتمد ومباشر لجميع العمليات المالية ومجموع التبرعات المفحوصة والمقبولة.
   - **التحقق الرقمي من العضوية (`/verify/[membershipNumber]`):** إمكانية مسح رمز الاستجابة السريعة (QR Code) على بطاقة العضوية للتأكد من سريان العضوية دون كشف معلومات الاتصال الخاصة.
3. **دليل المديريات الجغرافية والمحليات:** قاعدة بيانات تفصيلية لتمثيل المحليات في ولايات السودان المختلفة وأماكن تواجد أبناء الطائفة.
4. **شجرة العائلات التفاعلية وسجل الأنساب:** تصفح وتدقيق شجرة النسب العائلية الممتدة مع ربطها بإحصائيات دقيقة وإعدادات قابلة للتحديث الإداري.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الإطار البرمجي:** [Next.js (v16)](https://nextjs.org/) مع دعم معايير React 19 والتحميل السريع والـ Turbopack.
- **قاعدة البيانات والأمان:** [Supabase](https://supabase.com/) مع استخدام `@supabase/ssr` و `@supabase/supabase-js`.
- **التنسيق وتصميم الواجهات:** [Tailwind CSS](https://tailwindcss.com/) مدمجاً مع نظام المتغيرات اللونية الخاص بالهوية البصرية للمنصة.
- **مكونات التصميم:** [shadcn/ui](https://ui.shadcn.com/) المبنية على Radix UI لتوفير واجهات وصول مثالية متكاملة وسهلة الاستخدام.
- **الخطوط البرمجية:** خط `Tajawal` الموجه عبر حزمة `@next/font/google`.

## 🚀 تشغيل وتطوير المشروع محلياً

### المتطلبات المسبقة:
تأكد من تثبيت بيئة تشغيل [Node.js](https://nodejs.org/) (الإصدار 18 فما فوق) ومدير الحزم المفضل لديك (`pnpm` أو `npm`).

### 1. تثبيت الحزم التابعة:
```bash
pnpm install
```

### 2. تشغيل خادم التطوير المحلي:
```bash
pnpm dev
```
افتح الرابط [http://localhost:3000](http://localhost:3000) في متصفحك لمشاهدة الموقع والتفاعل معه مباشرة.

### 3. بناء نسخة الإنتاج النهائية:
```bash
pnpm build
```

## 📐 تنظيم هيكلية المشروع

- `app/` : يحتوي على كافة الصفحات والمسارات الفرعية (مثل الصفحة الرئيسية، صفحة التحقق من العضوية، الشفافية المالية، لوحة الإدارة `/admin`).
- `components/` : المكونات البرمجية المشتركة وقوالب الواجهات (الهيدر، الفوتر، القوائم التفاعلية، شاشات الترحيب).
- `lib/` : يحتوي على ربط خدمات Supabase (`lib/supabase/`) وإجراءات السيرفر (`lib/actions/`).
- `supabase/` : يتضمن ملفات الهجرة والتأسيس SQL (`supabase/migrations/` و `supabase/seed.sql`).
- `docs/` : التوثيق المعماري الشامل للنظام المالي والأمني وقواعد البيانات.
