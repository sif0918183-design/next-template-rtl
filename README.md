# منصة السادة الركابية الرقمية الموحدة في السودان 🇸🇩

مرحباً بك في المستودع البرمجي الرسمي لمنصة **السادة الركابية**، وهي البوابة الرقمية المتكاملة والديوان الرسمي الجامع لأبناء السادة الركابية في جمهورية السودان وخارجها. تهدف هذه المنصة إلى توثيق الأنساب، وتقديم الخدمات التكافلية والاجتماعية، وتسهيل التواصل وبث الأخبار والبيانات الرسمية تحت مظلة الأمانة العامة.

---

## 🌟 مميزات المنصة الرئيسية

1. **الخط العربي الاحترافي (Tajawal):** تم تزويد الموقع بخط "تاجوال" الراقي والأنيق لضمان تجربة قراءة فائقة الجودة تدعم الاتجاه من اليمين إلى اليسار (RTL) بشكل مثالي ومتكامل مع الهوية البصرية الفخمة (الأخضر الزمردي الملكي والأمبر الذهبي العتيق).
2. **لوحة التحكم الإدارية الشاملة (`/admin`):** لوحة تحكم عصرية ومحمية تمكن المشرفين من إدارة محتوى الموقع بالكامل دون الحاجة لتعديل الكود المصدري:
   - **تعديل النصوص:** تحديث العناوين، الشعارات، البانرات التعريفية، والنصوص الإرشادية لجميع الصفحات.
   - **أرشيف الأخبار والبيانات:** إمكانية إضافة، تعديل، وحذف الأخبار والبيانات العاجلة وتصنيفها.
   - **الوسائط المتعددة:** إضافة وحذف الصور والفيديوهات في معرض الميديا الرقمي.
   - **قاعدة بيانات النسب والعائلات:** إضافة وتحديث بيانات الأشخاص، والشجرة العائلية، وتعديل إحصائيات السجل المدني.
   - **إدارة الخدمات والتكافل الاجتماعي:** تعديل الخدمات المتاحة، ودعم الطلبات، وإضافة قنوات التواصل المباشرة.
   - **ميزة الاستعادة الكلية:** خيار لإعادة جميع البيانات التفاعلية إلى حالتها الافتراضية بنقرة واحدة.
3. **طبقة المزامنة التفاعلية اللحظية (`state-store.ts`):** تطبيق متطور يعتمد على حزمة React المتفاعلة وذاكرة التخزين المحلية للوصول المباشر ومزامنة البيانات في الوقت الفعلي عبر مختلف التبويبات والصفحات، مع دعم التوافق الكامل مع معايير SSR لـ Next.js لمنع الأخطاء البرمجية أثناء التحميل الأولي.
4. **دليل المديريات الجغرافية والمحليات:** قاعدة بيانات تفصيلية لتمثيل المحليات في ولايات السودان المختلفة وأماكن تواجد أبناء الطائفة.
5. **شجرة العائلات التفاعلية وسجل الأنساب:** تصفح وتدقيق شجرة النسب العائلية الممتدة مع ربطها بإحصائيات دقيقة وإعدادات قابلة للتحديث الإداري.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الإطار البرمجي:** [Next.js (v16)](https://nextjs.org/) مع دعم معايير React 19 والتحميل السريع والـ Turbopack.
- **التنسيق وتصميم الواجهات:** [Tailwind CSS](https://tailwindcss.com/) مدمجاً مع نظام المتغيرات اللونية الخاص بالهوية البصرية للمنصة.
- **مكونات التصميم:** [shadcn/ui](https://ui.shadcn.com/) المبنية على Radix UI لتوفير واجهات وصول مثالية متكاملة وسهلة الاستخدام.
- **إدارة الحالة والمزامنة:** نظام مخصص مدمج في `lib/state-store.ts` يضمن تحديث واجهات المستخدم مباشرة عند حفظ التعديلات من لوحة التحكم.
- **الخطوط البرمجية:** خط `Tajawal` الموجه عبر حزمة `@next/font/google`.

## 🚀 تشغيل وتطوير المشروع محلياً

### المتطلبات المسبقة:
تأكد من تثبيت بيئة تشغيل [Node.js](https://nodejs.org/) (الإصدار 18 فما فوق) ومدير الحزم المفضل لديك (`npm` أو `pnpm` أو `yarn`).

### 1. تثبيت الحزم التابعة:
```bash
pnpm install
# أو
npm install
```

### 2. تشغيل خادم التطوير المحلي:
```bash
pnpm dev
# أو
npm run dev
```
افتح الرابط [http://localhost:3000](http://localhost:3000) في متصفحك لمشاهدة الموقع والتفاعل معه مباشرة.

### 3. بناء نسخة الإنتاج النهائية:
```bash
pnpm build
# أو
npm run build
```

## 🔒 دليل لوحة التحكم الإدارية (`/admin`)

يمكنك الوصول إلى لوحة الإدارة الشاملة للموقع بالانتقال إلى الرابط المباشر `/admin` أو بالضغط على زر **"لوحة التحكم"** الموجود في القائمة العلوية للهيدر أو في تذييل الصفحة (الفوتر).

- **تسجيل الدخول:** يتم تأمين الواجهة بطلب رمز إداري محاكٍ لتأمين الواجهة من العبث. (الرمز التوضيحي الافتراضي لغايات المحاكاة والتجربة هو: `admin123`).
- **حفظ التغييرات:** بمجرد إجراء التعديلات في أي تبويب (سواء تعديل نص، أو إضافة خبر، أو تحديث وسيطة)، اضغط على زر "حفظ" المقابل لتحديث البيانات فورياً عبر كامل المنصة.
- **استعادة البيانات الأصلية:** في حال الرغبة في التراجع عن التعديلات وإرجاع المنصة لبياناتها التجريبية القياسية، يمكنك استخدام خيار "استعادة البيانات الافتراضية" المتوفر في تبويب الإعدادات العامة للوحة التحكم.

## 📐 تنظيم هيكلية المشروع

- `app/` : يحتوي على كافة الصفحات والمسارات الفرعية (مثل الصفحة الرئيسية، صفحة النسب، صفحة الخدمات، لوحة الإدارة `/admin`).
- `components/` : المكونات البرمجية المشتركة وقوالب الواجهات (الهيدر، الفوتر، القوائم التفاعلية، شاشات الترحيب).
- `lib/` : يحتوي على البيانات المرجعية الافتراضية (`mock-data.ts`) وملف إدارة ومزامنة الحالة النشطة للمنصة (`state-store.ts`).
- `public/` : الملفات الثابتة والرموز والصور المستخدمة.
- `app/globals.css` : التنسيقات العامة للموقع ومحددات الألوان الملكية الخاصة بالهوية البصرية.
